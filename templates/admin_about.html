Rollback points

Each update backs up the files it replaces, under instance/update_backups/. These hold code, not data - rolling one back undoes an update and leaves your requests exactly as they are. Restore one from a shell: python update.py rollback --to <name>. Deliberately not a button here - the case it exists for is a portal that won't start.

Database backup & restore

This app's entire database - requests, admin settings, the scanner's cache - and nothing else. Not to be confused with the rollback points above, which are application code, not data; neither can restore the other.
